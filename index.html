How to Play

  • The Host: Invents a secret password. You can type hints in the live chat to guide or trick the bots.
  • The AI Bots: Will systematically try to guess your password code based on their core parameters.
  • Game Over: You win if the bots run out of collective guess tries. You lose if a bot cracks it!
